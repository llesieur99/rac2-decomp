# s136os_functions.txt — selector for functions compiled by SN 2.95.3 v1.36.
#
# Each row: <region> <unit> <function>
#   <region>: usa|eu
#   <unit>: unit path without extension (e.g. text/248B50)
#   <function>: function name (e.g. func_00315940)
#
# The s136os_splice.sh helper compiles each selected function with SN 2.95.3
# v1.36 -fopt-stack and splices its .ent..end block into the unit's cc1 2.9
# output, so the image carries C compiled by the compiler the ROM's function
# was built with.
#
# Example:
#   usa text/248B50 func_00315940
#   usa text/248B50 func_003159B0
#
# See tools/ee/s136os_splice.sh for the implementation.
